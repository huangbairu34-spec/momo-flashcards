# 墨墨记忆卡（Markji）考研卡包合集

按「墨墨记忆卡」批量制卡规范整理好的 `.txt` 卡包，全选复制 → 粘贴进 App 的「批量制卡 → 从文本导入」即可。

## 内容

| 卡包 | 内容 | 说明 |
| :--- | :--- | :--- |
| 英二单词大观 | 2,868 词 | 按考频分为 8 个卡包，另有全量总包 |
| 英一单词大观 | 同源 | `英一_` 前缀的平行版本 |
| 考研英语作文主题词 | — | 历年真题主题词及拓展 |
| 信号与系统公式宝典 | — | 小马哥公式速查卡 |

## 导入步骤

1. 挑一个 `.txt`（新手建议先导 `01_词根型_超高频(考频10次以上)_记忆卡.txt`，310 词）
2. 打开文件，全选复制
3. 墨墨记忆卡 App → 「+」→「批量制卡」→「从文本导入」→ 粘贴 → 识别

按单元逐册导入可以打开 `按章节细分/`、`按章节细分_英一/`，里面每册 15~30 词，随背随导。

```text
├── 英一单词大观*_记忆卡.txt       # 英一全量总包
├── 英二单词大观*_记忆卡.txt       # 英二全量总包
├── 00_*_记忆卡.txt              # 作文主题词、信号与系统公式
├── 按章节细分/                   # 英二逐册卡包
├── 按章节细分_英一/               # 英一逐册卡包

```
